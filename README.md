# Jogo da Memória — DevWeb I

Jogo da memória desenvolvido para navegador utilizando **JavaScript puro**, **HTML5** e **CSS3**. O objetivo é encontrar todos os **8 pares** no menor número de jogadas possível para bater o seu próprio recorde.

Projeto desenvolvido como parte da **Avaliação C3** da disciplina de **Desenvolvimento Web I**.

---

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página e do tabuleiro.
* **CSS3:** Estilização, layout em grade (*Grid*), animações das cartas e responsividade.
* **JavaScript (Vanilla):** Lógica de embaralhamento, controle de estado das jogadas, verificação de pares e registro de recorde.

---

## Status do Projeto

**Versão atual:** Protótipo inicial (Primeiro Commit)

Esta primeira entrega estabelece a base funcional do jogo e serve como ponto de partida para avaliar os próximos passos do desenvolvimento, com foco em:
